【控制流：摄像头从哪来、怎么启停】
启动时： CameraService.@PostConstruct → CameraMapper.listEnabled()（MySQL 查启用的摄像头）
管理员操作： CameraController → CameraService → CameraMapper（增删改查）
↘ FfmpegManager.start/stop/restart（启停 FFmpeg 进程）

【数据流：一帧图像的旅程】
摄像头(RTSP / HTTP MJPEG)
│
▼
FFmpeg 进程（每路一个）  ← 解码 + fps抽帧 + 编码JPEG + 写stdout
│  JPEG 字节流
▼
FfmpegManager.readFrames()  ← 读字节，按 FF D8 / FF D9 切出一张张 JPEG
│  包成 InferFrame(帧号 + cameraId/vehicleId/driverId + 时间戳 + JPEG)
▼
InferFrameQueue（有界队列，满丢最旧）
│
▼
InferWorker（攒批：攒够 20 帧 或 等满 100ms）
│  一批 List<InferFrame>
▼
InferClient（multipart 一批 JPEG → HTTP POST）
│
▼
FastAPI /predict（ResNet50 推理 + OOD：max_p / energy / knn_dist / is_ood）
│  返回 JSON results
▼
InferClient 解析成 List<InferResult>
│
▼
