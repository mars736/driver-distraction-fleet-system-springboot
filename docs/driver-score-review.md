## 核对内容

- 权限：Security 层限制角色，Service 层限制司机本人；JWT 仍查库验证启用状态和 tokenVersion。他人和不存在统一 404；司机不能查看排名，也没有对外改分入口。
- 数据来源：仅统计 alert_record 的 SMS_ALERT/BACKLOG，不联结一对多的申诉事件/处理历史，不按车辆现绑定司机推算归属；普通帧、速度异常不扣分。
- 状态：OPEN/CONFIRMED 计有效扣分；直接撤销、申诉撤销均依据同事务提交的告警 status 重算。重复处理不重复回补，事务回滚不改变结果。
- 月份：北京时间半开区间，月末毫秒及闰月边界明确，跨月撤销只影响原月份；分数到 0 后保留实际累计扣分，撤销一条不等于直接加 5 分。
- SQL：所有输入参数使用绑定变量；沿用 driver_id/captured_at 联合索引的查询条件，时间列不套函数。排名先聚合、计算并列名次，再分页；同分按司机 ID 稳定排序。
- 分页：使用 long offset；明细/排名的列表和总数在同一 REPEATABLE_READ 只读事务中读取。新增同步测试强制让其他事务恰好在列表与总数之间提交告警或司机，当前响应仍保持原快照，库内新增记录也确实已提交。
- 兼容：不新增业务表、不改写原始识别和短信状态；H2 只用于 test，不进入生产运行依赖。
